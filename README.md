# ChurchReport

**A web application for managing Sunday church services, attendance, and reports.**

ChurchReport is a web application designed to help a church community organize its weekly service information, manage members and visitors, track attendance, and generate printable service reports.

## Features

The application is currently under development.

- **Dashboard:** Quick access to the main features.
- **Sunday Reports:** Prepare service reports with the preacher's name, sermon title, and key points.
- **Members & Visitors:** Organize community records and track attendance.
- **Statistics:** Review attendance trends over time.
- **Print Reports:** Preview and print Sunday service reports.

## Tech Stack

- **React** — User interface
- **Vite** — Development server and build tool
- **Tailwind CSS v4** — Styling
- **React Router** — Client-side navigation
- **Lucide React** — Icons
- **Appwrite** — Planned authentication and database integration

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/church-report.git
   ```

2. Navigate to the project directory:

   ```bash
   cd church-report
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
